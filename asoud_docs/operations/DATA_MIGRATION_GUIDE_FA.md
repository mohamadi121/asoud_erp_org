# راهنمای مهاجرت داده ASOUD ERP

## اصل کنترل

هیچ فایل واقعی مستقیماً وارد Production نمی‌شود. فایل منبع ابتدا
Read-only نگهداری، SHA-256 آن ثبت، یک نسخه پاک‌سازی‌شده تولید و روی Site
مهاجرت مستقل آزمایش می‌شود.

## ترتیب داده‌ها

1. Company، شعبه، سال و دوره مالی
2. کدینگ و تفصیلی‌های شناور
3. مشتری، تأمین‌کننده، کالا، خدمت و انبار
4. مانده حساب‌ها، اشخاص و موجودی کالا در یک تاریخ Cutoff
5. چک‌های باز، بانک، صندوق و تنخواه
6. اسناد باز خریدوفروش و اطلاعات مرجع موردنیاز

## کنترل‌های الزامی

- تعداد رکورد منبع و مقصد برای هر نوع داده
- جمع بدهکار و بستانکار و اختلاف صفر
- مانده هر Customer و Supplier
- تعداد و مبلغ چک‌های باز به تفکیک وضعیت
- موجودی تعداد و ارزش هر کالا/انبار
- Trial Balance، Balance Sheet و Profit and Loss در تاریخ Cutoff
- نگهداری شناسه منبع برای Trace و جلوگیری از Import تکراری

## ممنوعیت‌ها

- اصلاح دستی نتیجه برای برابرکردن کنترل‌ها ممنوع است.
- داده نامعتبر Skip نمی‌شود؛ در Exception List ثبت می‌شود.
- رمز، Token، شماره کارت و فایل شخصی غیرضروری مهاجرت نمی‌شوند.
- Migration با داده واقعی بدون صورت‌جلسه تطبیق حسابدار Accepted نمی‌شود.
