سند نیازمندی محصول و معماری ASOUD HR

نسخه ۲.۰ — یکپارچه با ASOUD ERP

ERPNext/Frappe v15 · Flutter Web PWA · Custom App: asoud_hr

تاریخ: ۱۴۰۵/۰۵/۰۴ — وضعیت: Technical Baseline

این نسخه جایگزین فرض «محصول مستقل + Next.js + موبایل فاز اول» است و ASOUD HR را از ابتدا بخشی از پروژه اصلی تعریف می‌کند.

۱. تصمیمات و مرز معماری

  • ASOUD HR ماژول دامنه‌ای ASOUD ERP است و پایگاه داده یا احراز هویت جدا ندارد.
  • رابط فعلی فقط Flutter Web PWA است؛ Next.js و اپ Native از دامنه جاری حذف شدند.
  • Holding، Company، Branch، User Context، Access، Approval، Delegation، Idempotency و Audit از asoud_core استفاده می‌شوند.
  • Coreهای Frappe و ERPNext تغییر نمی‌کنند.
  • حضور، مرخصی و Payroll به بررسی و نصب نسخه سازگار HRMS v15 در آینده وابسته‌اند.

۲. دامنه اجرایی

HR-1 — سازمان و پرسنل

Position Instance با ظرفیت، انتساب تاریخ‌دار، جلوگیری از حلقه مدیریتی و هم‌پوشانی، توسعه Employee، مدارک خصوصی، تاریخچه وضعیت و پروفایل پایه.

HR-2 — گزارش کار

یک گزارش فعال برای هر کارمند/روز، فعالیت‌های متعدد، محاسبه زمان، کنترل تناقض و اتصال به Approval مدیر مستقیم یا HR.

HR-3 — مکاتبات و اقدامات

نامه، درخواست، اطلاعیه، گزارش، دستور و پیشنهاد با گیرنده/رونوشت، محرمانگی، Thread پاسخ، View Log و اقدام دارای مسئول و مهلت.

HR-4 — داشبورد و PWA

داشبورد عملیاتی، فهرست پرسنل، گزارش و مکاتبه، ثبت سریع و Ribbon دسکتاپ منابع انسانی.

HR-5 — کنترل و پذیرش

Scope سمت سرور، Redaction، Private File، Audit، Idempotency، migration، تست، Build و UAT.

APIهای اولیه شامل dashboard، organization، employees، employee_profile، work_reports، save_work_report، request_work_report_approval، communications، create_communication، communication_detail، add_reply، create_action و notifications هستند.

  • شناسه ملی برای کاربر غیرمجاز Mask و در permlevel بالاتر نگهداری می‌شود.
  • مدارک باید File خصوصی باشند.
  • اعلان محرمانه متن کامل را افشا نمی‌کند.
  • View Log و Audit قابل حذف نیستند.
  • Mutationهای حساس Idempotency Key دارند.

۵. معیار خروج و موارد معوق

  • نصب app ششم در image و Site واقعی
  • ساخت همه DocTypeها و Custom Fieldها در migration
  • Policy گزارش روزانه با مدیر مستقیم/HR
  • عبور تست Backend، Gateway، Flutter Analyze و Release Build
  • عبور Metadata Gate و HTTP Smoke Test
معوق: موبایل Native، Push موبایل، Offline Draft موبایل، حضور و غیاب، مرخصی پیشرفته، Payroll، KPI پیشرفته، AI و SMS بیرونی. این سند درباره تکمیل آن‌ها ادعایی ندارد.
