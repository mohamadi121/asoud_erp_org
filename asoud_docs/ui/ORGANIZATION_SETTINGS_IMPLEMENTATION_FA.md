# پیاده‌سازی تنظیمات سازمانی

نسخه: 0.19.0  
پلتفرم: Flutter Web PWA و Frappe/ERPNext v15

## محدوده اجراشده

- داشبورد تنظیمات با پوسته ثابت پروژه
- نمای ساختار هلدینگ، شرکت و شعبه
- تنظیمات عمومی مالی
- فرم چندمرحله‌ای هلدینگ (۳ مرحله)
- فرم چندمرحله‌ای شرکت/شخص حقیقی (۴ مرحله)
- فرم چندمرحله‌ای شعبه (۴ مرحله)
- تغییر فیلدهای هویتی بر اساس نوع شخصیت حقیقی یا حقوقی
- نگهداری زمینه فعال Company/Branch
- API فهرست ساختار و ثبت idempotent واحد سازمانی
- اعتبارسنجی فیلدهای الزامی و نرمال‌سازی ارقام فارسی/عربی

## قراردادهای API

- `GET /api/method/asoud_core.api.organization_settings_snapshot`
- `POST /api/method/asoud_core.api.save_organization_unit`

در عملیات ثبت، `payload` یک JSON و `idempotency_key` الزامی است. ایجاد و ویرایش
فقط برای نقش‌های `System Manager` و `Accounts Manager` مجاز است.

## مدل حسابداری

- هر Company حسابداری، سال مالی، نمودار حساب‌ها و صورت‌های مالی مستقل دارد.
- Branch عملیات، انبار، صندوق، کاربران، سری اسناد و گزارش عملکرد مجزا دارد.
- حسابداری قانونی Branch از Company مادر ارث‌بری می‌شود.
- Holding امکان گزارش تلفیقی و حذف معاملات درون‌گروهی را فراهم می‌کند.

- `flutter analyze`: بدون خطا

- تست `asoud_core`: ۶۱ تست موفق
