# پیاده‌سازی تنظیمات مالی ASOUD ERP

نسخه: 0.21.0

وضعیت: برش اول فنی

## دامنه این برش

- تنظیمات مستقل در سطح Company فعال
- ارز دفتر کل ایران به‌صورت کنترل‌شده روی IRR
- انتخاب الگوی ثبت‌شده نمودار حساب‌ها
- انتخاب واحد ورود مبلغ بین ریال و تومان
- انتخاب نمایش تقویم شمسی یا میلادی
- نمایش سال‌های مالی قابل استفاده برای شرکت
- نمایش دوره‌های قفل‌شده
- ذخیره idempotent با مجوز `Accounts Manager` یا `System Manager`
- ثبت تغییرات در زنجیره حسابرسی ASOUD
- رابط RTL واکنش‌گرا در Flutter Web/PWA
- ایجاد و ویرایش حساب گروه یا سندپذیر بدون تغییر ERPNext Core
- تعریف چند نوع تفصیلی مجاز برای هر حساب سندپذیر
- الزام حداکثر یک نوع تفصیلی، تفصیلی پیش‌فرض و بازه اعتبار قواعد
- کنترل تعلق حساب، تفصیلی و قواعد به Company فعال
- اعتبارسنجی قواعد در زمان ثبت Journal Entry و انتقال به GL Entry
- نمای تجمیعی نگاشت حساب و تفصیلی در PWA

## قراردادهای API

- `GET asoud_iran.api.financial_settings_snapshot`
- `POST asoud_iran.api.save_financial_settings`
- `GET asoud_iran.api.account_detail_rules_snapshot`
- `POST asoud_iran.api.save_chart_account`
- `POST asoud_iran.api.save_account_detail_rules`
- `GET asoud_iran.api.eligible_floating_details`

هیچ تنظیم مالی فقط در وضعیت Flutter نگهداری نمی‌شود و Backend مرجع نهایی
اعتبارسنجی، مجوز و ثبت تغییرات است.

## قاعده اتصال حساب معین به تفصیلی

حساب مستقیماً به یک شخص مشخص متصل نمی‌شود. روی حساب سندپذیر، نوع یا
انواع تفصیلی مجاز مانند مشتری، تأمین‌کننده یا کارمند تعریف می‌شود و رکورد
واقعی تفصیلی هنگام ثبت سطر سند انتخاب خواهد شد.

- حساب گروه اجازه تعریف قاعده تفصیلی ندارد.
- حساب و تفصیلی باید در همان Company فعال باشند.
- فقط یک نوع تفصیلی فعال می‌تواند برای یک حساب اجباری باشد.
- هر قاعده می‌تواند بازه اعتبار و تفصیلی پیش‌فرض داشته باشد.
- قواعد منقضی‌شده هنگام ثبت سند معتبر نیستند.
- انتخاب تفصیلی خارج از نوع‌های مجاز توسط Backend رد می‌شود.
- تمام خطوط GL، کد و نوع تفصیلی را برای گزارش‌گیری مستقل نگهداری می‌کنند.

## ادامه این بخش

1. ایجاد و ویرایش سال مالی و دوره‌های مالی از PWA
2. تعریف حساب‌های پیش‌فرض دریافتنی، پرداختنی، درآمد، هزینه، صندوق و بانک
3. عملیات شماره‌گذاری نهایی برای بازه انتخابی
4. قفل و بازگشایی کنترل‌شده دوره با ثبت دلیل و مجوز
5. تنظیم حساب مقصد نتیجه عملکرد بر اساس نوع شخصیت و Company
6. ماتریس نگاشت حساب‌ها برای گزارش تلفیقی هلدینگ
